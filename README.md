# Алкаунтер

Офлайн-калькулятор общака для организатора похода.
PWA, данные в `localStorage`, бэкап — JSON-файл.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

После первого открытия можно «Установить на экран Домой» — дальше работает без интернета.

## Ссылка для друзей

На вкладке **Итог** → «Ссылка для просмотра».  
В ссылке лежит снимок поездки: друзья видят балансы и траты, но не могут править.  
После изменений у себя — отправь ссылку заново.

## Как пользоваться

1. Создай поход, добавь людей.
2. Впиши траты: сумма, кто платил, на кого делим.
3. На «Сборе» отмечай, кто уже скинул тебе.
4. На «Итоге» — кого дожать и кому вернуть; копируй тексты в чат.

Меню ☰ → экспорт/импорт JSON.
